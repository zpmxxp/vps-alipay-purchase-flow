## 支付宝付款时容易踩的坑

### 把美元价格和人民币扣款混为一谈

官网购物车以美元标价，支付页面可能会呈现换算后的金额。最终以支付宝确认页或结账页当时显示的金额为准，不要拿旧汇率手动估算后认定差额就是错误扣款。

### 只看年均成本，没看一次性应付金额

年付折算到每月看起来可能更低，但下单时通常要一次支付完整周期的费用。先确认预算能覆盖订单总额，再选择周期。

### 忽略机房与网络线路差异

同是 KVM VPS，地区和线路可能不同。不要只按内存或磁盘容量选购；如果你对机房有要求，确认套餐名称和订单摘要中对应的位置及线路信息。

### 付款后重复点击提交

如果支付宝显示已扣款，但订单页面暂时没更新，先刷新订单状态或检查账户后台，不要立刻再次支付。需要联系支持时，准备好订单号和支付凭证，描述实际发生的状态即可。

### 相信过期优惠码或教程

搜索结果里有不少较早发布的搬瓦工购买教程，也有页面宣称优惠码有效或失效；这些说法可能随时间变化。若官网购物车或结账页没有明确显示优惠生效，就不要把某个折扣码计入预算。付款前看到的订单金额才是你本次应核对的数字。
